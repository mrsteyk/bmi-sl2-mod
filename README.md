# Bright Memory Infinite SL1.5->SL2 DLSSG bridge

This is a Proof of Concept for a SL1.5->SL2 conversion. There's no configuration, you have to recompile the code yourself if you wish to change any settings :tf:

It expects you to put Streamline 2 files in `STK_MOD` folder where the executable lies, and you must inject it yourself at the earliest convinience. Maybe ASI loaders can work, I haven't tested.
