# Bright Memory Infinite SL1.5->SL2 DLSSG bridge

This is a Proof of Concept for a SL1.5->SL2 conversion. There's no configuration, you have to recompile the code yourself if you wish to change any settings :trollface:

It expects you to put Streamline 2 files in `STK_MOD` folder where the executable lies, and you must inject it yourself at the earliest convinience. Maybe ASI loaders can work, I haven't tested.

```
C:.
│   BrightMemoryInfinite-Win64-Shipping.exe
│   DX12.lnk
│   steam_appid.txt
│
└───STK_MOD
        nvngx_dlss.dll
        nvngx_dlssg.dll
        sl.common.dll
        sl.dlss.dll
        sl.dlss_g.dll
        sl.interposer.dll
        sl.pcl.dll
        sl.reflex.dll
```
